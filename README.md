# 📇 Sistema de Gestión de Contactos en Python

## 📋 Descripción del proyecto
Este proyecto consiste en el desarrollo de un sistema de gestión de contactos en Python, diseñado para almacenar, organizar y administrar información personal de clientes de manera eficiente.

La aplicación permite registrar nuevos contactos, editar información existente, eliminar registros y realizar búsquedas rápidas por nombre o número de teléfono, facilitando la gestión de datos de forma intuitiva y estructurada.

## 🎯 Objetivo
Desarrollar una aplicación funcional que permita gestionar contactos de manera segura y organizada, aplicando buenas prácticas de programación, estructuras de datos y programación orientada a objetos.

## 🛠️ Tecnologías y herramientas utilizadas
- **Python**
- **Programación Orientada a Objetos (POO)**
- **Listas y diccionarios**
- **Funciones y métodos**
- **Pruebas funcionales**
- **Documentación técnica**

## ⚙️ Funcionalidades principales
- ➕ Registro de nuevos contactos
- ✏️ Edición de contactos existentes
- 🗑️ Eliminación de contactos
- 🔍 Búsqueda por nombre o teléfono
- 📂 Organización estructurada de datos

## 🧩 Estructura técnica
El sistema fue desarrollado utilizando clases para representar cada contacto y gestionar sus atributos, aplicando principios de encapsulación y organización modular del código.

Se implementaron estructuras de datos como listas y diccionarios para almacenar y manipular la información de manera eficiente.
